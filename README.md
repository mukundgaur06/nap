# Nap - Notes App

A lightweight, full-stack web application for creating and managing personal notes.

## 🚀 Live Demo
[Try the app live on Railway](https://web-production-fedca.up.railway.app)

## 🛠️ Tech Stack
* **Backend:** Python (Flask)
* **Database:** Supabase (PostgreSQL)
* **Hosting:** Railway
* **Version Control:** Git & GitHub

## 🏃 Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/mukundgaur06/nap.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set up environment variables in a `.env` file:
   ```env
   SUPABASE_URL=your_supabase_url
   SUPABASE_KEY=your_supabase_key
   FLASK_SECRET_KEY=your_secret_key
   ```
4. Run the app:
   ```bash
   python app.py
   ```
